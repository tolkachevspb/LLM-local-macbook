# Changelog

## [1.0.0] — 2026-03-27

### Добавлено
- Двухколоночный веб-интерфейс: сайдбар с историей сессий + основная область чата
- Сохранение истории сессий в `localStorage` — данные не теряются при перезагрузке
- Переименование чатов (кнопка ✏️ в сайдбаре)
- Защита от случайного удаления чата (двухшаговое подтверждение)
- Рендеринг Markdown: заголовки, таблицы, списки, цитаты, ссылки, жирный/курсив
- Подсветка синтаксиса кода (встроенная, без CDN): Python, JS/TS, Go, Rust, Bash и другие
- Кнопка "Копировать" для каждого блока кода
- Переключение GGUF-моделей прямо из UI без перезапуска прокси (`/admin/switch`)
- API `/admin/models` — список доступных моделей из папки `models/`
- API `/admin/status` — статус переключения модели (опрос во время загрузки)
- Оверлей со спиннером во время смены модели
- Слайдер температуры (0–1) в сайдбаре с сохранением в `localStorage`
- Редактируемый системный промпт в сайдбаре (скрываемый)
- Инкрементальный рендеринг при стриминге — обновляется только активный пузырь, не весь DOM
- Корректный выход из while-цикла стриминга через `break outer` + `reader.cancel()`
- `download-model.sh` с профилями: `qwen-7b`, `qwen-14b`, `phi3.5-mini`, `gemma3-12b`
- Возобновление прерванных загрузок через `curl -C -`
- Подсказки-кнопки на пустом экране (вставляются в поле ввода по клику)

### Изменено
- `proxy.py`: управление бэкендом вынесено в `switch_backend_async()` через `subprocess`
- `proxy.py`: логирование входящих запросов с ролью и фрагментом контента
- `renderChat()` больше не перезаписывает весь DOM при каждом токене
- Исправлена ошибка "Load failed" при отправке второго запроса
- Стартовый экран с предложениями вместо пустого чата
